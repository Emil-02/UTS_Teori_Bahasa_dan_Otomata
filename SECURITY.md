| Version | Supported |
| --- | --- |

## Reporting a Vulnerability

Proyek ini adalah tugas akademik dan tidak menangani data sensitif. Jika menemukan masalah keamanan, laporkan secara privat melalui GitHub Security Advisories pada tab **Security** repositori ini, atau hubungi pemilik repositori. Mohon jangan membuka issue publik untuk laporan kerentanan.
